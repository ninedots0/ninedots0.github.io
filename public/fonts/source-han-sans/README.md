# Source Han Sans Simplified Chinese subsets

Source: Adobe Source Han Sans, release branch, SubsetOTF/CN (Regular and Bold).
https://github.com/adobe-fonts/source-han-sans

SIL Open Font License: see LICENSE.txt.
Only CJK characters currently used in src are included. Latin uses Geist.
New characters not covered by these subsets use the CSS system-font fallbacks.
WOFF subsets were produced with fontTools; full source fonts are not shipped.
Internal modified-font family: 9dots Han Sans.
